# Translation Documentation

For this translation, new words had to be coined, and words loaned in from English. This document contains those coined words/loan words, for clarity sake.

## Common terms

- pahdep padanyei - Scoutmaster (leader + scout)
- nwran heika - guidebook (book+direction/way)
